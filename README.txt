V6 — REAL BOOK SPREAD

Open index.html in a modern browser.

Interaction:
- Desktop: drag the OUTER RIGHT edge toward the spine to go forward.
- Drag the OUTER LEFT edge toward the spine to go backward.
- Hover near the outer edge to see the paper corner lift.
- Arrow keys and bottom buttons also work.
- Mobile becomes one-page reading mode with the same physical turn logic.

Personalizing:
- Replace the text directly in index.html templates p0–p7.
- Replace the photo placeholders in p2 with <img src="photos/your-photo.jpg"> if desired.
- Add music.mp3 beside index.html and set <audio id="bgMusic" src="music.mp3" ...> in index.html.

This version intentionally uses a true open-book layout with center gutter, page block thickness, left/right physical turning rules, and one active turning sheet. It avoids card-stack behavior.
